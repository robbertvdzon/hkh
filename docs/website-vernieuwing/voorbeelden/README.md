# Voorbeeldschermen (indruk van menu en look en feel)

Statische voorbeeldpagina's om de voorgestelde structuur te beoordelen. Dit is geen code van
de app; de pagina's zijn losse HTML-bestanden met vaste inhoud en zijn hier alleen als
screenshot en als bron opgenomen. Open een `.html`-bestand in een browser om zelf te kijken.

De stijl volgt de bestaande testapp (donkergroene kop, Libre Baskerville voor koppen, crème
en saliegroen als achtergronden). Het menu toont de zes hoofdingangen uit het structuurvoorstel
plus de knop "Lid worden" en een zoekveld dat pagina's én collecties doorzoekt.
