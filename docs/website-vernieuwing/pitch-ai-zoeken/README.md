# Voorstel AI-zoeken voor het bestuur

`voorstel-ai-zoeken.pdf` is het printbare voorstel (zeven pagina's A4) voor de bestuursvergadering:
probleem, oplossing met schermafbeeldingen, een echt voorbeeldantwoord, hoe het werkt, kosten,
veelgestelde vragen, gevraagd besluit en instructies om het zelf te proberen.

`voorstel-ai-zoeken.html` is de bron; na een wijziging opnieuw naar PDF printen met Chrome
(`--headless --print-to-pdf`). Het voorbeeldantwoord komt uit
`voorbeeldantwoord-aardbeienteelt.json` (één AI-zoekronde op productie, 16 oktober 2026).
